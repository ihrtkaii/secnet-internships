# secnet-internships

A private tracker that surfaces **security** and **networking / infrastructure** internships — SOC, AppSec, GRC, pentest, network engineering, NOC, sysadmin, cloud/platform infra, and IT support roles — instead of general software/data/quant listings.

This is a fork of the automated internship-tracking engine, retargeted with a security/networking title filter (`filters_secnet.py`) in place of the upstream tech filter. The scraping, dedup, and publishing pipeline is otherwise unchanged.
